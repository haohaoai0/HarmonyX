# 帖子特殊内容适配现状

2026-10-10 复核，以当前 `XPostCardParser`、`XRichCardParser`、`XStructuredCardParser`、`XTimelineParser`、`Tweet` 模型和共用帖子组件为准。这是代码覆盖清单，不能替代每种类型的真实账号和真机验证。

| 类型 | 当前情况 | 仍缺的内容 |
| --- | --- | --- |
| 普通链接／大图摘要卡 | 封面、标题、说明、域名和链接；`summary` 为横排小图，`summary_large_image` 为大图；兼容数字前缀卡片名 | 真实帖子视觉复核 |
| 投票 | 原生选项、结果比例、截止状态、投票请求及返回状态复查；文字／图片选项；卡内可播放媒体解析；兼容数字前缀且保留 CAPI 原始名称 | 真实账号投票提交及视频投票样本复核 |
| 空间直播／预告／录音／结束贴 | 原生空间卡、真实详情、头像空间圈、预览弹窗、收听及系统日历入口 | 官方 App 完整推荐模型、加入／发言／反应功能未公开接入；实时推荐外观仍需对应实时数据验证 |
| 图片／普通视频／GIF | 现有媒体组件和查看器 | 不能把它们的支持等同于所有第三方 player 卡支持 |
| 转帖／引用／社区帖子 | 有上下文及社区来源组件；引用共用投票、空间、文章、富卡片和可见性组件 | 各种真实引用包装复核 |
| 视频直播 `broadcast` | 有状态／观看人数字段、详情加载、可用流的原生播放器与外链 | 真实直播／回放接口和播放验证、房间头像状态 |
| 活动 `event` | 有已返回时间、倒计时及系统日历入口 | 完整活动详情、官方提醒订阅和真实样本验证 |
| 应用卡 `app` | 有应用信息、平台、评分和商店入口；支持经典绑定及结构化 `CardAppStoreDetailsComponent` | 各平台真实样本；商店入口不代表 HarmonyOS 可安装 |
| Unified card 多组件／轮播 | 经典 JSON 和无绑定的 GraphQL 结构化布局均解析；保留组件顺序、每页媒体、每个按钮的独立落点；横排媒体卡有专用布局 | 开发者自定义模板、尚未确认的组件；各种真实轮播视觉／落点验证 |
| 第三方 `player`／音频卡 | 可用直接流接入现有播放器；无可用流时保留真实 `player_url` 入口 | VMAP/XML 清单解析、iframe 专用播放器、独立音频样式 |
| 商品／购物卡 | 已有标题、价格／折扣字段及购买入口；保留每页商品媒体和落点 | 完整购物／结算流程、真实价格及商品样本验证 |
| X Articles | 共用文章卡、原生文章页面、正文块及富文本解析；详情和引用均传递文章字段 | 完整文章接口及多种正文块的真实样本验证 |
| 列表／社区／关注包／资料等分享卡 | 有原生路由及列表／社区／资料详情加载；结构化列表卡保留成员数量和作者 | 卡片内关注／加入操作、关注包详情和真实数据验证 |
| 社区笔记 | 有帖子展示字段、详情弹层及评价服务代码 | 真实笔记详情／提交回执验证 |
| 广告／AI 生成／内容披露 | 有披露字段解析和共用标签组件 | 各披露样本和相关操作验证 |
| 删除、不可用、受限、订阅专属等占位 | 有可见性模型、真实返回说明及动作限制；未知类型保留原帖入口 | 各种真实限制包装的验证 |

通用卡渲染只意味着信息可以展示并打开链接，不代表专用类型已经完整适配。新增类型应沿解析器、模型、共享组件、引用／转帖／详情、实际接口与真机验证整条链路实现。

本次修正的协议依据为本地保存的 X 官方 responsive-web 代码：`.codex/account-privacy/native-chunk-46807.js` 的 Card 转换器。结构化布局覆盖 `CardVerticalStackLayout`、`CardSwipeableLayout`、`CardCollectionLayout` 和 `CardModelExplorerLayout`；组件覆盖媒体、横排媒体、图文、按钮组、应用详情、列表详情及成员头像。未知开发者模板继续保留原帖入口，不声称已经原生适配。

首页与详情的差异已用真机响应确认：Android `HomeTimeline` 使用 `tweet_card.legacy`，网页 `TweetDetail` 使用 `card.legacy`。解析器同时读取两个入口（包括引用／转帖及投票），避免详情显示卡片而信息流丢失。回归样本保留盈透真实帖子卡片的字段结构，去掉推广跟踪参数。

链接／广告网站卡片按用户提供的官方信息流截图显示：封面使用接口原始尺寸比例，标题单行叠在封面底部，灰色来源域名放在封面下方；视频沿用原生播放器，独立静音按钮避开标题。网站封面、标题及来源打开该页自己的链接，静音按钮只控制声音。仅合并同一落点的普通媒体和网站详情，含商品／应用／动作或不同落点的组件保留完整布局；敏感媒体继续使用原有提示和显示控制。经典大图摘要保留 `image_value` 尺寸，零宽空标题不显示空浮层；缺少尺寸的图片使用有限的默认比例。

回归测试：`node --test tests/post-website-cards.test.cjs tests/post-rich-cards.test.cjs tests/post-polls.test.cjs tests/space-posts.test.cjs`，包含无绑定卡片、legacy 同级字段、引用／转帖、按页落点、轮播前后共享组件、视频／GIF 格式、无效链接、未知类型回退及网站卡片的比例／来源／合并约束。

本次验证：42 项回归通过；`devecocli run --module entry --device 5MT0225B19003950` 编译、安装、启动通过。真机原首页响应的 34 条帖子，在修正 `tweet_card` 入口后解析出 7 张卡片（修正前为 0）；新版真实信息流已显示链接卡片及视频卡片的标题浮层、来源行和声音入口。静音点击及截图中三个广告的逐条播放尚未完成真机复核。其他特殊类型仍按表中的真实样本验证缺口处理。
