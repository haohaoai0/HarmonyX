# 启动页

在“设置 → 外观 → 动画与触感 → 启动动画”选择四种模式，
下次冷启动生效，默认保留“灵动开场”。模式和速度均持久化，并归入华为云同步的外观偏好。

- **直接进入**：不显示应用内图标或启动动画，直接创建首页；也不等待桌面图标查询。
- **保持图标**：显示当前桌面图标，首页就绪后用 180 ms 淡出，不缩放。
- **iOS 风格**：图标保持至少 420 ms，首页就绪后轻缩至 0.82 倍，
  再放大并淡出背景，露出下面已经刷新的首页。仅动画 transform/opacity。
- **灵动开场**：按当前桌面图标和浅色/深色主题播放原有本地开场动画，
  结束且首页就绪后淡出，末帧静图保持衔接。选中时可调播放速度：
  0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×，默认 1×；其他模式隐藏此项。
  使用 Video 原生 `currentProgressRate`，不影响帖子视频或其他动画。

`pages/Startup` 仅提供轻量首帧，首个空闲帧或 32 ms 兜底立即通过
`UIContext.getRouter().replaceUrl` 替换为 `pages/Index`。动画在首页遮罩中播放，
因此账号恢复、缓存读取、首页刷新与动画并行，不再等视频播完才创建首页。
已渲染的首页帖子或本轮加载结束（含空数据/失败）允许退场。网络慢或离线时，
原生两种模式最多等 2200 ms，灵动开场的播放器看门狗为 `2500 / 倍速 + 1500 ms`，
遮罩额外保留 180 ms 退场时间（1× 时分别为 4000/4180 ms，0.5× 时为 6500/6680 ms）兜底
退出，随后显示首页原有的加载/空态/错误界面。减少动态效果时动画模式显示静态图标，
首帧后直接退出；切到后台、销毁或返回键退出时不会遗留遮罩计时器。

启动页不发起网络请求，不等待帖子、账号接口或推荐配置。应用在后台停留超过
10 分钟后重新进入前台会触发一轮缓存开屏；10 分钟内返回不显示。OAuth 回调和
跨设备恢复仍走原入口。返回键可以
提前结束首页遮罩。引导页和推荐弹窗等待遮罩移除后再展示。

`module.json5` 必填的 `startWindowIcon` 指向 `start_window_empty.svg`，只保留
系统启动窗口的浅色/深色背景。系统的桌面展开动效仍由系统负责，所选动画从
首页遮罩接管画面。后台返回的缓存开屏不重播冷启动动画。

## 修改画面

- `components/StartupAnimation.ets`：静音播放本地动画，末帧用于首页衔接。
- `utils/StartupAnimationSource.ets`：桌面图标与当前浅色/深色主题到 25 个视频的映射。
- `resources/rawfile/startup/`：原片及精确末帧静图；默认图标在 Harmony X 使用
  Classic 动画，在 Croak X 使用 Blue Frog 动画。
- `startup_animation_size` 和 `startup_animation_*`：动画容器尺寸与背景色。
- `utils/StartupSession.ets`：展示时间和一次性遮罩状态。
- `services/StartupSettingsStore.ets`：四种模式、七档速度的持久化与非法值回退。

“直接进入”跳过品牌动画层；缓存推荐开屏仍按独立规则判断。

背景色按视频**原始分辨率解码后的外圈 10% 主色**取值，不平均 Logo 像素，
也不先缩放 YUV 视频再取色（缩放会引入 RGB 舍入偏差）。25 段原片与末帧图
均已核验：浅色 `#FBFDFA`，深色 `#000000`，蓝色 Twitter `#00A7F0`。
原生模式的蓝底白鸟保留蓝背景，黑白 X 随主题调整墨色，避免不可见。
25 段视频的 MP4 `colr/nclx` 和 H.264 VUI 均显式标注 BT.601
（SMPTE 170M 矩阵，limited range），避免硬件播放器把未标记视频按 BT.709
解码。蓝色视频用错矩阵时会从 `#00A7F0` 偏到 `#009BF6`，与外围背景形成色块。
修复仅以 stream copy 补充矩阵和范围元数据，不重新压缩、不改动视频帧；
`scripts/tag-startup-video-colors.py --backup <目录>` 会保存原片并逐帧核对解码后的
YUV 校验和。原片未声明的色彩原色和传递函数保持未指定。
验证脚本：`scripts/verify-startup-video-backgrounds.py`，使用 `--ffmpeg` 指定解码器，
`--report docs/startup-video-backgrounds.json` 生成逐视频证据；同时核对浅色、深色
资源、末帧静图和容器/码流的颜色矩阵、范围标记。背景资源覆盖整个启动层和安全区。
元数据核验及软件解码不能替代真机硬件播放的视觉验收。

路由替换失败时启动页显示现有的“重试”按钮；启动页资源加载失败时
EntryAbility 自动回退到首页。组件销毁会清理计时器并忽略过期帧回调。

测试：`node --test tests/startup-page.test.cjs tests/notification-launch.test.cjs tests/xxauth-splash.test.cjs tests/xxauth-promotion-post.test.cjs tests/home-exit-confirmation.test.cjs tests/huawei-account-cloud.test.cjs`。

## 开屏广告展示区

`SplashAdSurface` 是独立展示组件：上方广告标记与可立即点击的跳过按钮，
中央圆角区域用同一应用的多张介绍图拼成磁贴背景，叠加渐变阅读区；
下方是明确的行动按钮与当前应用图标的品牌签名。
跳过按钮将倒计时放在独立细环中，读屏只播报“跳过”。普通浏览区域不能触发跳转。

多图使用三列错位磁贴，横屏和宽屏改为五列铺满区域；卡片带圆角与细描边，
图片在磁贴内裁切，底部渐变保护文字对比度。只有一张图时回退为完整比例海报，
宽屏文案置于右侧，低矮窗口精简说明并允许文案滚动。
共享 EntryAbility 已有的窗口尺寸、避让区域和监听清理流程。
底部品牌区和顶部控件支持浅色/深色。

新增文案在所有 21 种资源语言中提供。日常启动由 `StartupLaunchCover` 接入
XXAuth 的每应用推荐记录，配置见 [云端推荐开屏配置](xxauth-splash.md)。

开屏仅使用已完整缓存的图片与图标，缓存有效期 24 小时。首页复用原有推荐
配置请求异步准备下一次冷启动素材；当前启动不等待网络。支持者权益只读取
本地加密缓存，最多等待 120 ms，读取失败或没有已登录账号时跳过广告。
引导、登录、分享入口不插入开屏；普通返回前台会覆盖当前内容展示广告，结束后
留在原有位置。广告点击打开外部应用后返回时豁免一次，避免循环弹出。

默认每次打开均可展示，云端每日上限和最短间隔均设为 0；每次 1–5 秒且始终可立即跳过。
海报加载后首个空闲帧才计曝光并开始倒计时；500 ms 内未就绪则直接进入首页。
后台开关刷新为关闭、账号切换、支持者权益生效或应用进入后台时立即退出。
已展示应用在本次运行中不再弹同款推荐。开屏频次独立于推荐弹窗的次数和免提醒，
支持者免推广权益继续生效。每次前台进入只领取一次，重复生命周期通知不会连弹。

只有明确点击行动按钮才可能跳转；点击后最多用 1 秒复核当前云端开关、
应用记录和目的链接，失败时回到首页。跳过、销毁或后台切换会取消待跳转操作。
素材目前支持图片，不播放视频。

`开屏图片` 支持多行 HTTPS 图片；配置多张时以该列表为准，只有一张或未指定
时用本应用的 `帖子媒体` 图片补齐，去重后最多 6 张，跳过视频。每张图独立缓存，
补充图失败时只省略该图；主图或图标不可用时仍跳过本轮广告，不跨应用借用素材。
