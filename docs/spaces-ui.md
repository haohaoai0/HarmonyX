# 空间原生界面

参考空间截图更新了以下入口，子页统一使用 `HdsNavDestination`、共享标题栏样式与 API 26 官方 `ImmersiveMaterial`，保留 API 23 回退。所有新增文案提供中文、英文和意大利文资源，颜色提供浅色及深色版本。

| 页面或操作 | 实现 |
| --- | --- |
| 空间列表 | 默认来自账号自己的关注流（Spaces 标签页的 fleetline，其次关注账号分享的空间链接），全站最新分享仅作兜底并单独标注；原生搜索；直播、预告、回放分区；紫色卡片、主持人简介、参与人数与头像 |
| 空间悬浮按钮 | 与发帖共用 `FloatingComposeButton`；只替换颜色、Symbol 和点击功能，保留拖动、握姿、材质及按压效果 |
| 更多菜单 | 原生菜单；分享；按账号保存不感兴趣的空间；在 X 官方页面完成举报 |
| 收听页 | 官方沉浸式子页；预览主持人与发言人；收听后显示公开成员的四列网格；收听、暂停、重试、离开与分享 |
| 首次使用、录音说明 | 官方沉浸式说明子页；首次确认后调用真实收听服务；可随时从房间标题栏查看说明 |
| 成员 | 官方沉浸式成员子页；全部、共同主持人、发言人、听众筛选；头像连接现有用户主页 |
| 后台收听 | 复用现有 AVPlayer/HLS 和系统音频会话；回到首页后显示收听栏，可重新打开房间或停止 |
| 预告提醒 | 打开系统日历事件编辑页，由用户确认保存；默认提前 10 分钟提醒，时长可在系统编辑页修改 |
| 准备空间 | 名称、录音偏好、最多三个话题及未来 14 天内排期；按账号保存本机草稿 |

空间搜索使用 `AudioSpaceSearch`，该操作只接受 `POST`；此前用 `GET` 会返回 404，搜索结果因此被悄悄替换成全站链接列表。

空间目录按来源分三层：`/fleets/v1/fleetline?only_spaces=true`、关注账号分享的空间链接，最后才是全站最新分享。前两层为空时目录标题显示“发现空间”并说明这是全站排序。

首页标题栏接入共享 `SpaceSurfaceStore`。候选来自服务端空间流、真实首页返回的空间注入、关注账号分享的空间，以及关注用户的独立 `avatar_content` 空间状态。保留服务端候选顺序，去重并补全实时详情；关联关系可以发生在主持人、共同主持人、发言人或听众，不能要求主持人必须被关注。全站最新分享不会直接注入首页推荐。X 官方的 [空间推荐机制](https://help.x.com/en/resources/recommender-systems/spaces-recommendations) 还包含语言、历史收听、话题、热度与模型排序；这些未公开的模型输出未在本地伪造，当前接口也不保证与官方 App 的推荐完全一致。

标题栏胶囊复用刷新胶囊的 `MaterialButton`，为 API 26 `ImmersiveMaterial` 添加主题色 `materialColor`；三个重叠头像、原生纵向 Swiper 状态轮播、按 scaleY 动画的声纹，点击打开全局原生预览弹窗。手机底部弹窗与大屏居中弹窗使用现有材质设置；没有候选时不占高度。

从首页胶囊打开预览后，“更多”菜单支持“仅本次关闭”和“直接关闭”：前者只隐藏当前启动会话，下一次启动恢复；后者保存关闭状态，重启仍保持关闭。两者均收起弹窗及标题栏胶囊的占位，可在“设置 → 辅助功能、显示和语言 → 显示 → 首页交互 → 首页空间胶囊”重新开启。开关作用于首页胶囊，不改变正在收听的音频、帖子中的空间卡片或头像空间状态。

首页底部收听栏沿用回复胶囊的 `Navigation.title` builder 挂载方式与 `ImmersiveMaterial` 参数：跟随回复胶囊的材质厚度设置，启用交互与自动反色，关闭材质阴影，使用 32vp 圆角裁切。API 23–25 保留卡片底色；展开、暂停、重试和关闭继续使用同一播放服务。

| 新增适配 | 数据和交互 |
| --- | --- |
| 直播分享贴 | `audiospace` 绑定或真实 expanded Space URL，补全主持人、认证、标题、人数与动态声纹，点击预览并收听 |
| 预告分享贴 | 真实预约时间；预览后打开系统日历编辑页 |
| 已结束及录音分享贴 | 开始时间、真实时长、直播累计听众加回放次数；录音可播放，没有录音则显示已结束 |
| 引用、转帖、帖子详情、v2 | 复用 `PostInteractiveContent` 与同一 Space 卡片解析及缓存 |
| 帖子、引用、详情、用户列表、用户主页头像 | 独立批量查询 `/fleets/v1/avatar_content?only_spaces=true&user_ids=...`；按返回的刷新间隔缓存；漏返回的用户清除状态；视频直播不冒充空间；点击空间圈打开预览 |
| 生命周期 | 可见头像才轮询；离屏或后台停止；实时状态过期清除；切换账号使未完成请求失效；详情请求合并；播放复用现有 AVPlayer/HLS 服务 |

收听复用 X 的真实详情与音频接口。没有提交加入、发言或麦克风推流请求，因此不展示可切换的匿名加入状态，也不生成虚假的发言、反应或评论计数。创建和排期表单明确标注本机草稿，尚不能发布到 X。成员列表仅展示接口公开返回的成员，不补造完整听众名单。

验证记录见 `outputs/space-surfaces-build.log`、`outputs/space-surfaces-install.log`、`outputs/space-surfaces-tests.log`。回归测试位于 `tests/x-spaces.test.cjs`、`tests/space-posts.test.cjs`、`tests/space-surface-store.test.cjs`。构建安装和接口/播放测试分别验证；真机音频状态需单独记录，不能由构建成功推断。
