# Pura X 外屏适配

## 布局范围

复用现有窗口尺寸监听与宽度断点。增加高宽比断点：小于 0.8 为横向窗口，
0.8 至小于 1.2 为近方形窗口，其余为纵向窗口。宽度小于 600 vp 的横向或
近方形窗口启用紧凑布局，适用于 Pura X 外屏及相似的小窗口。

官方参考：外屏约 326 × 326 vp（sm/md），内屏约 440 × 707 vp（sm/lg）。
布局以运行时窗口尺寸为准，不通过设备型号匹配。

## 实现

- 首页临时使用已有紧凑标题栏，并启用系统滚动隐藏标题栏、底部导航。
  展开后恢复用户保存的 Logo、自动隐藏设置，不改写偏好。
- 外屏隐藏首页的推荐 Space 胶囊，减少额外垂直占位；当前业务状态保持不变。
- 抽屉的账号头部与菜单整体滚动，所有原有菜单回调保持可访问。
- 共用半模态配置按可用高度的 90% 限制高度及挡位，去除重复挡位，保留键盘
  避让、关闭拦截及高度通知。详情、个人资料、社区、私信等页面显式订阅紧凑状态，
  内外屏宽度断点同为 sm 时也更新弹窗。
- 回复胶囊缩短编辑区，附件缩略图与输入框同行。完整编辑器与工具栏减少固定高度。
- 私信缩小附件缩略图和回复预览；键盘弹出时暂时收起附件预览，保留所选附件和
  回复对象，键盘关闭后恢复预览。
- 短视频操作栏支持局部滚动，Bilibili 布局的底部信息区限制高度并支持滚动。
  图片、视频评论面板使用同一窗口高度计算，继续保留媒体预览。
- 窗口尺寸变化不主动重建 AVPlayer、不清空路由或草稿；首页复用已有阅读锚点恢复。

## 悬浮底部页签

根页签直接声明 `barFloatingStyle`，由当前安全区和材质设置驱动首次渲染与后续更新，
不再在组件创建前修改 `HdsTabsModifier`。底部间距为系统导航区高度加 `8vp`，
无系统导航条的外屏和大屏窗口也保留悬浮间距。发布按钮、未读点和 Space 播放条
使用相同底部间距；不重建页签、不切换当前页面来触发布局。

后续修复验证：相关回归 54 项通过，构建和 Pura X 模拟器安装启动成功。
未切换任何根页签时，980 × 980 外屏冷启动的页签底部间距从 0px 变为 24px（8vp）；
展开到 1320 × 2120 后为 108px（系统导航区 84px 加 24px），再次折叠后仍为 24px。
节点边界、截图与构建日志位于 `.codex/floating-tabs-20261017/`。
该修复用于手机和现有大屏布局共用的 HdsTabs 分支；大屏真机尚未验证。

## 原生库架构

Windows 上的 Pura X 模拟器使用 x86_64，真机使用 ARM64。HAP 同时包含
`libs/arm64-v8a/libharmonyx_chat.so` 和 `libs/x86_64/libharmonyx_chat.so`，
已核对 ELF 的机器类型分别为 183 和 62。

本地原生构建脚本支持选择架构，例如在 PowerShell 中执行：

```powershell
.\native\xchat\build-local.ps1 -Abi @('arm64-v8a', 'x86_64')
```

两种架构的产物放入对应 `entry/libs/<abi>/` 目录后，再使用 `devecocli build` 打包。
本工程采用预编译原生库，不需要为此额外创建 CMake 工程。

外屏入口的官方发布流程要求先完成适配和调测、成功上架应用市场，再申请外屏展示。
此修改未增加任何用于绕过外屏展示审核的配置。
