# 图片和视频的一镜到底打开

参考文件：`D:/下载/familyActivity (1).zip` 中的 `FamilyActivityController`、`FamilyActivityCoverNode` 和 `ActivityPage`。压缩包仅作为实现参考。

没有可搬移节点的头像和横幅等待图片解码后再展开；视频等待播放器首帧或错误状态就绪后再展开，避免先放大空白表面。

采用同窗口坐标测量、360ms 原生弹簧、持久查看表面，以及动画结束后才移除路由的返回流程。动画通过缩放、平移、圆角裁剪和透明度完成，不逐帧改变播放器或 Swiper 的布局尺寸。

| 入口 | 接入路径 |
| --- | --- |
| 首页、搜索、个人页、详情、通知等帖子图片 | 共享 `PostMedia` → 根 `PhotoViewer` |
| 帖子视频和通知聚合里的视频 | `PostMedia` → `Index` / `NotificationPosts` → `VideoFeedViewer` |
| 个人头像、个人横幅 | `UserDetail` → `PhotoViewer` |
| 私信图片 | `ChatMediaCard` / `ChatMediaAlbum` → `PhotoViewer` |
| 私信视频 | `ChatMediaCard` → `DmConversation` → `ChatVideoViewer` |

帖子和私信图片通过 `BuilderNode` / `NodeContent` 搬移同一个图片节点。查看层完成起始几何布局后才接管图片，避免测量期间把缩略图移空。返回时先把原图节点还给原卡片，并在同一次提交中隐藏查看层，等来源完成一帧布局和绘制后才退出路由。退出销毁只失效回调，不把已经收回的动效重置成全屏。来源列表项被回收再出现时复用查看器持有的原节点，旧列表项迟到的清理不会释放新来源的节点；来源未再出现时由查看页回收节点。原图加载保留现有解码结果，迟到请求使用序号隔离，失败重试有上限。

帖子视频继续使用现有 AVPlayer handoff，保留播放器、缓存、播放时间和声音状态；查看层动画期间保留播放，避免裁剪引发暂停或自动进入画中画。视频依然由目标播放器的 XComponent 承载，未改成截图动画，也没有将源 XComponent 节点搬移到目标页。

视频收回完成后，按原始来源组件 ID 把同一个 AVPlayer 直接交还仍在列表中的播放器，在同一次 UI 提交中隐藏查看层，等来源提交一帧后再退页。返回豁免只属于该来源实例，重复帖子不会同时恢复播放。旧页面交出播放器后，其暂停、退出、后台状态和画中画清理不再释放接收方的播放所有权；接收方使用实际原生播放状态恢复已暂停的播放器。仍然存在的缓存列表播放器也会优先接回请求中的播放器，迟到的 AVPlayer 创建不能覆盖查看器的交接。来源已经销毁时回到原来的请求接管流程。

先前的最后一帧截图遮挡曾导致用户反馈黑屏，现已撤掉该方案及缓冲区读取，恢复常规 Surface 绑定。保留播放实例、进度和缓存，不依赖截图来判断原生表面已经显示。

图片缩放或下拉后直接从当前画面返回，不先重置到中心。来源横向列表中，当前图完整可见或部分可见时保留用户的精确滚动偏移；仅当当前图已不可见时才使用 `ScrollAlign.AUTO` 做最小幅度调整，并计入前导留白 ListItem 的索引。完成布局后测量图片当前位置。其他推荐视频、来源已回收或已离开视口时使用淡出，避免收回到另一条媒体。没有有效来源的路由保留系统转场。

多图查看器会预加载相邻页。关闭时先等待来源横向列表完成定位，再归还所有非当前图片节点，留出一帧让缩略图绘制后才开始收回当前图片。关闭期间冻结翻页，并统一拦截预加载和原图 URL 更新引起的再次接管，避免其他缩略图在返回途中变黑。当前图仍在收回结束后归还。

私信仍经过现有解锁、可见性和屏幕保护检查；本次没有改动解密或保存权限。

直接播放器归还与图片列表偏移修复后的编译通过，183 项图片、视频生命周期、布局、评论弹层、投屏、静音和私信媒体回归全部通过，包含连续三次视频往返、原生播放状态、缓存列表接管、重复帖子来源匹配、旧页面清理隔离、迟到播放器创建隔离，以及完整/部分可见缩略图保持偏移和前导留白索引。构建与测试记录保存在 `.codex/media-direct-return-build.log` 和 `.codex/media-direct-return-tests.log`。最新版本已安装并成功启动到 HUAWEI Mate 80 Pro Max（API 26），安装记录保存在 `.codex/media-direct-return-install.log`。遵照此前停止手机检查的要求，本轮读取了已有播放器日志，未自动操作手机验证返回观感；新版本的视频归位及图片列表偏移的实际视觉验收尚未完成。
