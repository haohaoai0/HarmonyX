# 评论弹窗内图片查看

评论列表、嵌套回复及引用配图通过 `PostMedia.onPhotoOpen` 交给当前嵌入式 `PostDetail`。普通信息流和独立详情仍使用原图片路由。`CommentPhotoViewer` 在弹窗内部持有导航栈并复用 `PhotoViewer`，不创建新的全局图片请求。

查看图片时，评论列表和回复输入组件保持挂载，仅设为 Hidden。返回按钮、系统返回及弹窗关闭拦截优先退出图片；外部关闭评论时清除回调，释放图片节点。图片切换、缩放、GIF 和长按操作沿用原查看器。

底部弹窗的内容区会扣除手势区，背景仍覆盖手势区。图片查看器使用父查看器通过 `onHeightDidChange` 回传的实际弹窗高度；在图片打开期间，嵌入式详情外层和内部导航同时按该高度布局，避免内部导航被安全区限制，也避免把整个窗口高度误作图片视口。居中弹窗和宽屏侧栏保留原有布局。操作按钮沿用查看器原有安全区内边距。
