# 离线收藏、场景模式与长线程阅读

## 使用入口

- 书签 → 离线与稍后读：按账号查看本地副本，搜索标题、标签和备注，筛选未读；“标签与备注”中可手动调整未读状态。
- 新增在线收藏会自动保存正文和可获取的长文。已有收藏可点“保存离线副本”；在离线列表中开启“后续保存包含配图”后，再保存需要的项目。配图保存包含照片和长文插图，不下载视频。
- 帖子详情 → 长线程阅读：默认只看作者，可切换完整讨论，调节字号、整段翻译并继续加载回复。离线副本也在此阅读，阅读位置与字号会保留，读到末尾自动标为已读。
- 设置 → 场景模式：清爽阅读、节能省流、媒体浏览，以及恢复原配置。手机与桌面共用设置目录。

## 保存与恢复语义

离线正文和图片保存在应用持久目录 `filesDir/offline_reading`；索引、标签、备注、未读状态和阅读位置按账号隔离。普通缓存清理不触碰此目录。取消在线收藏与删除本地副本各自独立，删除副本前需要确认。重新保存同一帖子保留本地备注、标签和进度。

长文优先补齐正文，再生成本地副本。正文接口失败、图片下载失败或线程还有未加载回复时，保存结果会提示不完整；不会把预览内容当作完整长文。读取本地副本只加载已保存的本地图片，不会通过图片地址悄悄联网。翻译操作需要联网，使用现有翻译设置；选择 X 翻译时，阅读器采用网页翻译处理整段正文，因为 X 接口只返回单条帖子译文。

阅读器只包含焦点帖明确的祖先链与可从该帖追溯到的回复，不把推荐内容拼成正文。分页沿用详情页的排序模式和游标。保存的是当前已加载内容，需先“继续加载”才能纳入更多讨论。

首次启用场景时，先保存自动播放、图片画质、视频画质、减少动效、符号动效和背景启用状态。连续切换场景不覆盖原备份；恢复成功后才清除备份。背景仅切换启用状态，保留照片、纹理和透明度。动效时长、阻尼等细调参数保持原值。场景内手动改动受控设置后，“恢复原配置”仍返回首次启用前的值。

## 验证

`node --test tests/reading-modes.test.cjs tests/settings-catalog.test.cjs tests/page-background.test.cjs`

覆盖线程归属与排序、长文完整性、纯文字/配图保存、账号隔离、删除与异步保存竞争、索引写入失败、重存保留本地标注、场景跨重启恢复与部分失败恢复。设备验收应另测断网重开副本、图片显示、编辑标签备注、阅读位置恢复、继续加载和翻译，并检查场景切换后的播放与背景。
