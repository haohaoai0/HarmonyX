# 大屏桌面布局

显示设置中的「大屏布局」切换持久保存，默认使用现有布局。入口为设置 → 辅助功能、显示和语言 → 显示。设置首页没有重复的布局入口；搜索「大屏布局」会找到现有的显示分类。

当前窗口宽度达到 840 vp 时启用桌面布局，低于此宽度恢复现有界面。840–1199 vp 使用紧凑导航，1200 vp 起显示文字导航和信息侧栏。聊天始终使用紧凑导航。左右外边距为 16 vp，其余空间供内容使用。导航栏使用 Harmony X 的品牌图标。

桌面布局的最右侧信息栏默认显示。点击栏顶部的关闭按钮，或在显示 → 大屏布局中关闭「桌面右侧栏」，可隐藏搜索、趋势及推荐区域；内容区自动填满释放的宽度，自动帖子列数按实际内容宽度更新。该选择持久保存，重启、切换布局及调整窗口后仍保留。重新开启使用同一设置开关，原有页面及窄窗口的侧栏隐藏规则继续生效。

关闭桌面布局时沿用原有大屏适配：840 vp 起显示常驻侧栏，1200 vp 起打开内容页时列表与详情并排。帖子详情例外，宽屏也直接进入完整内容页，返回后回到原信息流或上一级页面。原有根标题栏使用普通自定义构建函数；桌面布局仅在 API 26 及以上使用保留节点配置，较旧系统完全省略新增字段，避免旧 HDS 隐藏标题。底栏关闭「提醒」只隐藏底栏入口；侧栏和系统推送仍可打开通知目的页，并复用同一通知数据、筛选和刷新逻辑。

原大屏布局的内容起始位置按完整页签区域计算，在指示条下方保留 8 vp 间距；首页折叠标题栏和空间推荐胶囊也参与计算。手机和桌面布局继续使用各自的避让方式。

大屏首页、通知和帖子页在单列与多列之间始终保留 WaterFlow，不再因打开、关闭内容分栏切换成 List。使用 SLIDING_WINDOW 布局，仅更新正文分组列数，保留页头、页尾、数据源和 Scroller。Navigation 对普通内容页保留原生单双栏切换动画，帖子详情分支固定使用 Stack；HdsSideBar 的内容构建函数使用稳定引用。840–1199 vp 的页面仍为 Stack，打开内容页不会改变后台时间线列数。

图片、视频评论弹窗复用 SheetMaterial 的居中呈现判断。大屏居中弹窗打开或调整高度时，不缩小、上移媒体；图片保持已有缩放。窄窗口的底部评论弹窗继续保留媒体避让，跨断点调整窗口时同步恢复或启用相应布局。

标题栏使用 HdsNavigation / HdsNavDestination 原生组件级安全区和 bindToScrollable，首屏内容自动避让，滚动内容通过 clip(false) 和可见预加载穿透标题栏，原生渐变模糊处理覆盖区域。桌面标题栏的初始及滚动背景保持透明；不绘制额外的模糊条或黑色占位。底部内容末尾保留导航条避让距离。系统避让区、窗口宽高变化沿用 EntryAbility 的监听。

首页、探索、提醒、聊天与个人页的 Refresh 同步关闭大屏边界裁剪。探索复用其他根页面的原生账号行，保持相同高度和垂直对齐；搜索栏与分类页签在账号行实际底边下方使用 Column 依次排列，去除搜索栏的固定屏幕位置和分类栏原有的空白占位。正文避让由最后一行实际底边相对于正文容器的起点计算，原生底部槽位也按实际占用高度调整；不使用滚动页头的位置作为正文原点。分类栏基础高度为 52 vp，独立搜索栏、页签及桌面槽位随应用字体大小增长；紧凑模式的搜索控件仍使用共用账号行高度。搜索、历史、列表、Grok 与创作者工作室在大屏使用原生组件级避让，去除旧布局重复的顶部占位。设置列表与根导航共用标题栏样式解析，继续跟随显示设置中的沉浸渐变模糊、渐变模糊、玻璃材质及关闭沉浸模糊选项；支持 API 26 的设备直接在原生标题栏内容上应用已选玻璃厚度。

实现参照官方 [Navigation 分栏开发](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-navigation-split-mode)和 [Row/Column 线性布局](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-layout-development-linear)。HdsNavigation bottomBuilder 的 height 不支持百分比，使用实际测量值换算后的 vp；这是相对于内容的动态高度，并非固定屏幕偏移。

搜索结果标题栏的自定义输入框按大屏原生按钮的 32 vp 边距、40 vp 宽度再加 8 vp 间隔预留两侧空间。MatePad Pro 横屏实测：返回按钮右边界 627 px，输入框左边界 642 px；输入框右边界 1966 px，菜单按钮左边界 1980 px，均无重叠。

大屏 bindSheet 统一设置 preferType: SheetType.CENTER，保留关闭、键盘、回调及可选材质配置，并约束在当前窗口范围内。窄窗口保留原有底部弹层。

## 验证

2026-10-11 分栏连续性、居中媒体评论和探索相对布局修复：95 项相关检查通过，构建成功。API 24 平板打开、关闭书签分栏前后，Navigation、主页 WaterFlow 和已显示帖子的节点保持一致，视频播放时间从 0 秒连续推进至 7.65 秒。最新版本安装到 Mate 80 Pro Max（API 26），当前紧凑标题栏与放大字体设置下，首页、探索、通知的共用账号行均为 175–303 px；探索原生标题栏和分类页签底边同为 523 px。平板随后断开，最后的账号行对齐与标题栏延伸修复尚未在 API 24 平板复测。

2026-10-11 原大屏布局回归修复：42 项相关测试通过，构建成功并安装到 MatePad Pro（API 24）。恢复根标题栏、常驻侧栏、通知页和原有宽屏内容分栏；底栏隐藏通知的独立目的页有导航测试覆盖。真机首页指示条底部为 240 px、第一行内容顶部为 278 px；通知页分别为 244 px 和 282 px，均保留 38 px 间隔。

新增持久化、窄窗口回退、页面栏位、嵌套导航返回、弹层适配和标题栏样式选择测试；与首页时间线、媒体交互、照片重开测试合计 41 项通过。MatePad Pro（API 24）完成构建、安装和设置闪退修复验证。原闪退来自 DesktopSettingsHost 重复提供 pageStack，现按官方 allowOverride 参数建立局部导航作用域。

此前桌面布局首次验证时平板未登录 X，账号相关的关注、发布、聊天解锁和真实会话交互不作为该次设备验证结论。公开预览内容保留示例说明，侧栏不把示例趋势当作实时趋势。
