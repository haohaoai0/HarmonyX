# 帖子视频与 X 操作栏布局

设置 → 视频播控新增两个独立选项，默认均关闭：

- **帖子视频画面内播控**：取消视频下方的播控占位，在画面底部显示渐变衬底、播放/暂停、时间、静音、全屏和更多菜单。轻点画面显示/隐藏，播放时自动收起；更多菜单保留倍速、字幕、可用的画中画和视频操作菜单。
- **退出视频后暂停帖子预览**：视频查看器返回时保留原 AVPlayer、播放位置和缓存，将来源视频保持暂停。会话中的暂停记录跨卡片回收保留，可见性回调和自动播放不会覆盖它；主动点击播放解除暂停。画中画仍由原有所有者管理。

设置 → 媒体中的**帖子视频长按**可以选择操作菜单或长按快进。快进沿用现有长按倍速开关；关闭倍速时，长按视频左右两侧快退/快进。

视频信息流的普通竖屏播控区由 112vp 改为 80vp：28vp 进度条触控区、44vp 按钮区、8vp 底部间距。系统导航安全区额外计算。小方屏专用播控和横屏控制器保留各自布局。

设置 → 布局中的信息流列数新增四列、五列。自动模式仍为手机单列、适中窗口两列和宽屏三列。旧的“自动双列”存储值 4 保留；四列和五列分别使用新值 5、6，避免升级后改变原有选择。主信息流和共用的次级信息流均识别新模式；窄手机窗口不启用四/五列。
