# 哔站式视频信息流

入口：视频信息流右上角更多 → 信息流布局 → 哔站模式。经典、抖音模式保留；布局选择沿用 MediaSettingsStore，重启后保留。

## 行为

- 作者与帖子正文、分集和互动栏作为覆盖层展示。视频画面尺寸、填充设置、背景模糊与纯黑背景偏好均沿用原模式，不为新布局缩小视频或强制黑底。全屏播放与发弹幕胶囊复用 NewPostsPill 使用的 MaterialButton，材质等级 2、阴影开启。
- 播放仍由 PostMedia/SurfaceVideoPlayer 负责。新增全屏请求信号与弹幕 Builder；播放器、清晰度、缓存、手势、字幕、投屏和原有播放控件继续复用。
- 弹幕读取当前帖子的 TweetDetail 回复部分，最多 3 页、100 条。按父帖或会话 ID 过滤，排除推荐帖、空内容和重复 ID；移除文本中的链接和起始提及。原评论没有视频时间戳，按播放过程轮流展示。
- 弹幕保留评论的语言和完整原文，按现有自动翻译设置调用 TranslationService：使用真实回复 ID，遵循目标语言、跟随应用语言及排除语言。只翻译可见轨道，普通/全屏共用在途请求；关闭翻译或切换目标语言立即失效旧结果，翻译失败显示原文。发送内容不受显示翻译影响。
- 5 条轨道，每条最多一个可见节点；使用原生 translate 动画，暂停续滚，页面隐藏后停止调度。切帖、切集重新建立弹幕层。全屏覆盖层也显示弹幕。
- 发送前说明会公开回复原帖。复用 OAuth/private 发帖接口，确认回复 ID 后才加入本地弹幕。失败保留草稿；不确定的 OAuth 结果不会自动重试，避免重复发评；发送中的重复点击被拦截。
- 同帖多个可播放视频按原附件顺序列为分集，可展开选择。自动连播开启时，先播同帖下一集，再进入下一条推荐帖。敏感媒体继续遵循现有显示限制。
- API 26 以下沿用 MaterialButton 的纯色回退，不影响功能。
- 全屏播放胶囊首次显示 3 秒后隐藏；每次点击视频重新显示并重新计时。出现/消失使用 180ms 淡入淡出，遵循减少动态效果设置。暂停时同样计时，隐藏时不接受点击；切集、离开页面和展开评论时清理对应计时。
- 弹幕输入框使用 KeyboardAppearance.IMMERSIVE。弹幕编辑半模态按实际键盘高度扩展自身预留空间，再由 RESIZE_ONLY 避让，使 240vp 编辑区完整保留在键盘上方；只在弹窗可见期间监听键盘并在关闭后解除。设备布局证据：键盘上边界 1788px 时，SheetPage 为 [0,978][1320,1788]，输入框为 [67,1168][1253,1344]，发送标签为 [571,1444][750,1514]。
- 单击画面的操作可在视频更多菜单或设置→媒体中选择，默认保持显示/隐藏播控栏，也可改为暂停/播放视频。偏好持久化并由 EntryAbility 初始化，经典、抖音、哔站布局共用；视频预览评论关闭及长按手势继续优先处理。
- 点赞、转发、收藏与评论使用独立响应式按钮组件；选中颜色/填充、计数、等待中状态与禁点跟随真实操作状态。胶囊按钮启用按下缩放/明暗反馈，分集使用原生按钮状态效果。共享 MaterialButton 的新增反馈默认关闭，仅由此布局显式启用。
- 评论浮层展开时，哔站覆盖层跟随原有 commentPreviewProgress 淡出，顶栏返回/更多按钮、作者信息与底部互动栏同步收起，并关闭隐藏覆盖层的命中；评论关闭后恢复，不改播放器或背景。

## 布局与尺寸

沿用 EntryAbility 的窗口尺寸和断点 AppStorage，不增加窗口尺寸监听。手机使用信息覆盖层；平板沿用现有 56/44 播放区与帖子详情分栏。视频保持原显示区域、比例、填充方式和背景，播放器控制条保持原高度。

| 元素 | 手机 | 折叠与平板 | 倍数 |
| --- | --- | --- | --- |
| 弹幕文字 | 16fp | 16fp | 1.0 |
| 胶囊文字 | 14fp | 14fp | 1.0 |
| 互动计数 | 12fp | 12fp | 1.0 |
| 互动图标 | 24vp | 24vp | 1.0 |
| 全屏胶囊图标 | 18vp | 18vp | 1.0 |
