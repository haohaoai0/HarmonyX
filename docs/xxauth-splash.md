# 云端应用推荐接入开屏

复用现有 XXAuth 软件下的「每应用一条、优先级 15」推荐公告。应用名称、图标、
小注释、多行介绍和应用链接由同一条记录提供，弹窗、信息流和开屏各有独立开关。
无需另建接口。旧记录缺少开屏字段时默认关闭。

## 1. 配置程序变量

在 XXAuth 的「变量配置」中新增或修改以下变量，每个变量一行：

| 变量 | 启用示例 | 作用 |
| --- | --- | --- |
| `harmonyx_enabled` | `on` | 现有推广总开关 |
| `harmonyx_recommend` | `on` | 现有应用推荐总开关 |
| `harmonyx_splash` | `on` | 新的开屏渠道开关，未配置时关闭 |
| `harmonyx_splash_daily_limit` | `0` | 每台设备每日开屏上限，默认 0，即不限制 |
| `harmonyx_splash_interval_hours` | `0` | 两次展示的最短间隔小时数，默认 0，即不限制 |

也可在现有 `harmonyx_popup` JSON 中设置 `splash_enabled: true`、
`splash_daily_limit: 0` 和 `splash_interval_hours: 0`；独立程序变量优先。
现有弹窗渠道 `recommendation_enabled` 不控制开屏。只投开屏时可关闭应用的
「弹窗开关」及「信息流开关」，保留两个总开关和开屏开关为开。若仍需兼容
不认识开屏字段的旧版本，则保留「弹窗开关：开」：新版本展示开屏后会跳过同款
弹窗，旧版本继续按原弹窗路径展示。

## 2. 给目标应用追加开屏字段

保持原公告的应用标识、发布状态和优先级，在内容末尾追加以下字段。
`example.com` 是占位地址，发布前换成实际 HTTPS 图片地址：

```text
开屏开关：开
开屏图片：https://example.com/campaign/poster.jpg
开屏标题：让好奇，遇见同频。
开屏文案：发现喜欢的内容，遇见有趣的人。
开屏按钮：立即体验
开屏时长：3
```

| 字段 | 规则 |
| --- | --- |
| 开屏开关 | 必填为「开」才参与投放，关闭写「关」 |
| 开屏图片 | 支持多行 HTTPS 图片；每张最大 5 MB、1200 万像素；不支持视频 |
| 开屏标题 | 可省略，沿用该应用的「应用名称」 |
| 开屏文案 | 可省略，沿用该应用的「应用多行注释」 |
| 开屏按钮 | 可省略，使用当前语言的「立即体验」 |
| 开屏时长 | 右上角「跳过」旁的倒计时，默认 3 秒；限制在 1–5 秒；跳过始终可立即点击 |

公告必须发布，且该记录的「应用开关」为开，应用名称、图标和链接有效。
开屏目的地址共用「应用链接」，不从其他应用或旧版分散公告补齐。只新增
开屏图片不会自动启用开屏，也不会改变现有推荐帖的媒体。

`开屏图片` 只有一张或为空时，会从本应用的「帖子媒体」读取介绍图并补齐，
去重后最多 6 张，忽略视频。不需要重复维护现有应用介绍图。若要单独指定
开屏图库，在「开屏图片」下连续写多行图片 URL，该列表优先于帖子媒体。

画面上方显示广告标记与跳过倒计时，多张介绍图采用 Windows 磁贴式的错位
卡片拼图铺满推荐区背景，手机三列、横屏五列，底部与文字背后有阅读渐变。
只有一张有效图片时保留完整比例并用同图柔化填充背景。
应用图标和名称位于海报左上，标题、文案与行动按钮由客户端排版。
底部品牌签名沿用用户选择的本应用图标。建议图片聚焦视觉主体，避免把跳过、
按钮烘焙进图片；现有应用市场竖版截图即可，横屏会调整磁贴和文案布局。

完整新建记录可参考 [可复制模板](xxauth-splash-template.txt)。已有记录只追加
开屏字段，避免覆盖现有推荐帖、免提醒和渠道配置。

## 3. 展示与验证

客户端在正常首页配置刷新时下载并校验海报与应用图标，完整保存后供下一次
冷启动使用。第一次安装、首次配置、缓存缺失或超过 24 小时时跳过广告。
当前启动不等待素材下载。应用退到后台超过 10 分钟后重新进入前台会触发一次
热启动开屏；后台停留不超过 10 分钟或只有重复前台通知时不触发，不需要杀进程。

默认每天次数与最短间隔均不限制，每次打开只展示一轮。完成海报首帧才记一次曝光，
图片损坏或 500 ms 内未就绪直接进入首页。开屏有自己的频次，不受推荐弹窗的
每进程上限或三天免提醒影响。支持者继续免推广；权益缓存未就绪或没有已登录账号
时也跳过。账号切换、
后台切换、首次引导、登录和分享入口不会阻塞在广告上。

已展示的应用在同次运行中不再弹同款推荐弹窗，普通公告和更新提示继续按
原规则执行。旧版本没有开屏接入逻辑时，会忽略开屏字段并继续读取同一记录的
弹窗开关。点击行动按钮后复核当前云端记录，最多等待 1 秒，只有当前仍
开启且链接有效才跳转；失败直接返回首页，跳过后不会发生延迟跳转。

验证顺序：发布配置 → 正常打开首页等待后台缓存 → 完全关闭应用再冷启动。
热启动另测：进入后台恰好 10 分钟仍不应出现，超过 10 分钟后再进入前台应出现。
当前配置不限制频次，可以连续从桌面打开验证；若日后设置非零上限或间隔，
再按对应频次窗口检查。

## 关闭投放

关闭全部开屏：设置 `harmonyx_splash=off`。关闭某款应用的开屏：该条记录改为
「开屏开关：关」。关闭整款应用：改为「应用开关：关」或取消发布。
客户端收到关闭配置后清理待用素材记录并退出该应用的开屏，未完成的旧下载
不能重新启用它。离线启动可能沿用尚未过期的缓存，最长 24 小时；点击跳转
仍要求联网复核，不会直接使用旧目的链接。广告打开外部目的页后返回豁免一次，
再次从桌面打开恢复正常展示；重复前台通知不会让同次打开连弹。
