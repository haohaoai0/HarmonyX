# 设置分类

“外观与使用体验 → 首页与布局 → 首页交互 → 退出前确认”默认开启。主页面按返回键或侧滑返回时显示系统确认弹窗；关闭后使用系统默认返回退出行为。开关立即生效并跨启动保存，搜索“退出前确认”或“主页面返回”可定位。手机侧栏与子页面仍优先处理各自的返回。

设置首页按五个使用场景分组。入口只展示分类与用途，具体开关放到对应子页。手机和桌面设置共用 `SettingsCatalog.ets`，搜索返回实际包含选项的子页，并显示分类路径。

首页与分类子页卡片共用 16vp 的左右外留白。留白放在卡片外层容器，卡片只填满剩余内容宽度；桌面模式以当前设置分栏为宽度边界。滚动内容顶端对齐，避免短页面出现垂直居中的大块空白。

| 首页分组 | 分类及子页 |
| --- | --- |
| 账号与安全 | 账号、隐私、安全、已屏蔽账号 |
| 外观与使用体验 | 外观：主题与颜色、字体与文字、界面材质、应用图标；首页与布局：默认首页、导航与按钮、首页交互、大屏与帖子布局；图片与视频：图片查看、视频播放、视频画面与操作、查看器与评论、画质；通知：提醒与系统通知；操作与辅助 |
| 内容与语言 | 内容过滤；语言、翻译与 Grok；我的列表 |
| 数据与网络 | 代理；数据与存储 |
| 帮助与关于 | 更多资源（帮助、诊断）；软件介绍与版本 |

界面材质分别管理标题栏、页签、弹窗、侧栏和回复框。视频自动播放、静音、画中画与后台播放集中在“视频播放”。持握手、链接打开、按压反馈与朗读入口集中在“操作与辅助”。首页空间胶囊在“首页与布局 → 首页交互”中恢复。

“首页与布局 → 导航与按钮 → 液态指示器”可独立开启或关闭悬浮栏上的液态胶囊，立即生效并跨启动保存；经典导航栏下不启用。胶囊宽高随“显示 Tab 文字”同步变化，胶囊材质、图标和文字均沿用“组件 HDR 提亮倍数”，材质与前景分别应用一次，避免重复叠加。


本次只重新组织入口和展示，沿用原有 Store、保存回调、默认值及账号接口。弹窗材质关闭时的原有行为保留。已有账号页面的链接打开设置入口继续兼容。

喵推送入口暂时隐藏，设置分类及搜索均不展示。已有配置、设置组件和推送服务保留；此前记住的喵推送设置路由回到通知分类。

子页从自身 `NavDestinationContext.pathInfo.param` 读取分类，不再延时取同名路由的最后一个参数，避免多层设置返回后显示到另一页。

验证：分类可达性、搜索定位与路径、外部入口、全部语言资源，以及媒体和首页设置回归。2026-10-15 的留白修复已编译并安装到 HUAWEI Mate 80 Pro Max；外观分类卡片在 1320px 窗口中的横向边界为 [54,1266]，两侧留白一致。桌面分栏本轮未实机验证。


## 菜单配置接入（2026-10-18）

菜单操作的开关归入现有设置页，不增加独立菜单分类：

| 所属设置 | 接入内容 |
| --- | --- |
| 外观与使用体验 → 首页与布局 → 首页交互 | 帖子菜单的 9 个操作项 |
| 外观与使用体验 → 图片与视频 → 图片查看 | 图片长按菜单与查看器更多菜单的 11 个操作项 |
| 外观与使用体验 → 图片与视频 → 视频画面与操作 | 视频布局、播放控件常显、默认 AI 字幕，以及视频菜单的 14 个操作项 |
| 外观与使用体验 → 图片与视频 → 视频播放 | 查看器独立默认静音、播放结束自动前进 |
| 外观与使用体验 | 沿用私信设置页面，提供通知、请求、通话、PIN、数据与存储入口 |
| 外观与使用体验 → 首页与布局 | 沿用桌面卡片数据源设置页面 |

每个菜单操作默认显示，可单独隐藏；按组恢复默认保留其他组的偏好。实际显示仍遵循内容类型、所有权和能力支持条件。菜单与设置共用持久化配置，重启后保留；保存失败不会发布新的菜单配置。字幕和自动前进保留原先的默认值，并新增跨启动保存。设置搜索可按具体操作名定位到所属页面。


## 聊天设置入口与共享设置

聊天设置仅保留消息请求、通话权限、PIN、聊天自动下载和重置聊天。仅聊天推送统一放在通知提醒设置；聊天媒体保留时间与缓存清理统一放在数据与存储。旧的聊天通知和存储子页面跳转到统一页面。

聊天主页允许无参数进入，后台隐私设置仅在消息请求或通话页面加载。
