# Harmony X

面向 HarmonyOS 的原生 X 客户端。

[English](README.en.md)

本仓库用于发布应用安装包、更新说明和使用文档，应用源码在私有仓库维护。

## 下载与更新

前往 [Releases](https://github.com/haohaoai0/HarmonyX/releases) 查看版本说明并下载对应安装包。

各版本支持的设备、系统要求、签名状态和安装方式以对应 Release 的说明为准。

请在 Release 的 **Assets** 中选择 `.hap` 或 `.app.zip` 安装包。GitHub 自动生成的 **Source code (zip / tar.gz)** 仅包含本发行仓库的文档，不包含应用源码或安装包。

## 功能

- 浏览时间线、搜索、通知和用户主页。
- 发布动态、回复、点赞、转发与管理书签。
- 查看图片和视频，使用私信及个性化设置。
- 适配 HarmonyOS 多种设备和屏幕尺寸。

## 问题反馈

请通过 [Issues](https://github.com/haohaoai0/HarmonyX/issues) 反馈问题，并注明应用版本、设备型号、系统版本和复现步骤。请勿公开账号凭据或私人信息。
