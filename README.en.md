# Harmony X

A native X client for HarmonyOS.

[简体中文](README.md)

This repository hosts app downloads, release notes, and user documentation. Application source code is maintained in a private repository.

## Downloads and updates

Visit [Releases](https://github.com/haohaoai0/HarmonyX/releases) for release notes and installation packages.

Refer to each release for supported devices, system requirements, signing status, and installation instructions.

Choose a `.hap` or `.app.zip` installation package under the release's **Assets**. GitHub's automatically generated **Source code (zip / tar.gz)** archives contain only the documentation in this distribution repository, not the application source code or installation packages.

## Features

- Browse timelines, search, notifications, and profiles.
- Publish posts, reply, like, repost, and manage bookmarks.
- View images and videos, use direct messages, and adjust preferences.
- Use layouts adapted to different HarmonyOS devices and screen sizes.

## Feedback

Report problems through [Issues](https://github.com/haohaoai0/HarmonyX/issues), including the app version, device model, system version, and reproduction steps. Do not share account credentials or private information.
